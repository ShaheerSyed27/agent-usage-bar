# Documentation assets

These images are generated by the real `AgentUsageBar.exe` renderer with
representative demo values. They contain no signed-in account data.

| File | Suggested use |
| --- | --- |
| `01-overview.png` | README hero image or repository social preview |
| `02-reset-expiry.png` | Banked-reset and local-time feature section |
| `03-tray-status.png` | System-tray feature section |
| `04-reset-expiry-animation.gif` | Lightweight expiry-alert demonstration |
| `widget-light.png` | Raw light-mode widget capture |
| `widget-dark.png` | Raw dark-mode widget capture |
| `widget-expiry-alert.png` | Raw final-24-hours capture |
| `widget-claude-light.png` | Raw Claude light-mode capture |
| `widget-claude-dark.png` | Raw Claude dark-mode capture |

Regenerate the full set from the project root:

```powershell
powershell.exe -NoProfile -STA -ExecutionPolicy Bypass -File .\scripts\render-docs-assets.ps1
```

Build the executable first if the source has changed. The script relies only on
Windows PowerShell, .NET Framework, and the locally built executable; it does
not upload anything or require a third-party image tool.
