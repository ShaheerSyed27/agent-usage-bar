# GitHub and community media

The large examples use synthetic values and the real app drawing code, not an
AI-generated approximation. The one exception is `03-windows-taskbar.png`, an
unmodified, tightly cropped capture explicitly supplied for publication. It
shows a percentage and the Windows clock, with no account details or credentials.

- `01-overview.png`: 2560 x 1280, both providers in light and dark mode.
- `02-reset-expiry.png`: 2560 x 1440, the amber warning and real tooltip text,
  arranged into a readable presentation. Example dates use the render machine's
  local timezone, including the offset at each expiry date.
- `03-tray-status.png`: 2560 x 1280, a **taskbar mock**, with the app's actual icon
  renderer at normal and enlarged sizes. It is not a Windows desktop capture.
- `03-windows-taskbar.png`: the actual Windows taskbar at native resolution.
  It is intentionally not enlarged, reconstructed, or generated by the script.
- `04-reset-expiry-animation.gif`: 1680 x 640, eight seconds, 10 fps. Four seconds
  of amber warning, then four seconds of the red final-hour state. The transition
  is a demo jump, not accelerated countdown behavior.
- `04-reset-expiry-poster.png`: a non-animated alternative.
- `widget-*.png`: 4x bar renders, except `widget-light-native.png` at 276 x 64.

## Regenerate

Run in Windows PowerShell, not PowerShell's default MTA mode:

```powershell
powershell.exe -NoProfile -STA -ExecutionPolicy Bypass -File .\scripts\render-docs-assets.ps1
```

The optional animation encoder requires Python 3 with Pillow available to that
Python installation. Select it with `-PythonPath "C:\path\to\python.exe"`, or add
`-SkipAnimation` to generate only PNGs. The script does not install dependencies.
Python and Pillow are **not** required to build or run Agent Usage Bar.

The script compiles a documentation-only copy of the real drawing code into
ignored `dist/documentation`. Its GDI text adapter applies the export scale to
fonts and text coordinates, because GDI text ignores GDI+ scale transforms.
Grayscale font smoothing avoids ClearType color fringes in exported images.
Production builds do not include this adapter. Native-size exports use the
same scale and drawing primitives as the app.

No provider service is started, no model is called, and no fake usage is written
into the live cache. Temporary frames stay under ignored `dist/documentation`.
The GIF uses one adaptive palette with no dithering and verifies both animation
states after encoding. Re-rendering does not change the running widget.
The separate user-supplied taskbar capture is preserved unchanged.
